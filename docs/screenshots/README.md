# Screenshot Checklist

Recommended screenshot file names for portfolio material:

- `01-overview.png`: fleet overview dashboard.
- `02-machines.png`: machine list with pagination.
- `03-machine-detail.png`: machine detail with prediction/anomaly history.
- `04-shap-explanation.png`: persisted SHAP attribution section.
- `05-alerts.png`: operational alert monitoring.
- `06-drift.png`: drift monitoring for AI4I and anomaly inputs.
- `07-copilot.png`: local AI Copilot answering a source-grounded question.
- `08-api-docs.png`: FastAPI OpenAPI documentation.

Do not commit fake screenshots. Capture real local screenshots only after the dashboard and API are running.
