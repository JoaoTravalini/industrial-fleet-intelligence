## Data Quality
FACT: Missing values total 0; duplicated full rows total 0.
FACT: Unique UDI count is 10000 and unique Product ID count is 10000.
OBSERVATION: The raw dataset is left unchanged; this EDA produces only derived reports and static charts.

## Target Distribution
FACT: Machine failure has 339 positive observations out of 10000 (3.39%).
OBSERVATION: The target is class imbalanced because non-failure observations dominate the dataset.

## Key Observations
OBSERVATION: The dataset is structurally complete for the expected AI4I columns.

OBSERVATION: Failure-mode flags are sparse and target-adjacent by design.

## Modeling Considerations
FUTURE MODELING CONSIDERATION: The class imbalance should be handled deliberately during a later modeling phase, without changing the raw dataset here.
FUTURE MODELING CONSIDERATION: Failure-mode columns `TWF`, `HDF`, `PWF`, `OSF`, and `RNF` may have a very direct relationship with `Machine failure` and could cause target leakage if blindly included as model input features. This phase does not make the feature-selection decision.

## Limitations
FACT: This EDA does not perform preprocessing, feature engineering, train/test splitting, model training, or database import.
FACT: AI4I must not be described as real industrial data, proprietary data, or data generated by the local fictional fleet.
