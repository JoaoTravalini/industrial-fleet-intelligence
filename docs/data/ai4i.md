# AI4I 2020 Predictive Maintenance Dataset

The AI4I 2020 Predictive Maintenance Dataset is a public synthetic predictive-maintenance dataset from the UCI Machine Learning Repository.

## Project Use

AI4I is an external public synthetic dataset used in this portfolio project for future Data Science and machine-learning development. It must not be described as real industrial data, as Liebherr data, or as data generated by this project's fictional fleet.

The fictional `MCH-XXXX` PostgreSQL fleet represents operational application assets. AI4I is a separate external reference dataset. Future streaming telemetry will be generated by a simulator and will eventually flow through Kafka and Spark; it is also separate from AI4I.

Raw downloaded files are intentionally excluded from Git. Reconstruct the local raw dataset with `scripts/download_ai4i.py`, then validate it with `scripts/check_ai4i.py`.
