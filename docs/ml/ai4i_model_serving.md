# AI4I Model Packaging and Inference

## Frozen Model
The packaged AI4I model is the already-finalized fixed `RandomForestClassifier`. The model specification remains frozen in `ml/config/ai4i_final_model.json`, and that configuration hash is not changed by packaging.

## Artifact Packaging
Packaging reconstructs the frozen scikit-learn pipeline and fits it on the combined train + validation development data only. The final holdout test split is not read or used for packaging.

The generated model binary is local-only at `ml/artifacts/ai4i/final_model.joblib` and is intentionally ignored by Git.

## Model Version
The local packaged model identity is:

- Model name: `ai4i-failure-risk-random-forest`
- Model version: `1.0.0`

This package version is separate from the final model configuration hash.

## Artifact Integrity
Packaging writes local metadata to `ml/artifacts/ai4i/artifact_metadata.json`. The metadata records the model name, version, final configuration hash, binary SHA-256, serialization format, runtime library versions, training row counts, predictive features, and decision threshold.

The tracked summary at `reports/ai4i/model_packaging_summary.json` records reproducible packaging context without storing a binary checksum.

## Input Contract
Inference accepts exactly these predictive fields:

- `Type`
- `Air temperature [K]`
- `Process temperature [K]`
- `Rotational speed [rpm]`
- `Torque [Nm]`
- `Tool wear [min]`

`Type` must be one of `L`, `M`, or `H`. Numerical fields must be numeric, finite, non-null, and not boolean.

The inference contract rejects target, identifier, and leakage-sensitive fields such as `Machine failure`, `source_udi`, `UDI`, `Product ID`, `TWF`, `HDF`, `PWF`, `OSF`, and `RNF`.

## Output Contract
Each prediction returns:

- `failure_probability`
- `failure_prediction`
- `decision_threshold`
- `model_name`
- `model_version`
- `final_config_hash`

## Decision Threshold
The frozen threshold is `0.14`. Inference uses `predict_proba()` and applies `failure_probability >= 0.14` manually. The estimator default `predict()` threshold is not authoritative for this project.

## Single Inference
Run the default sample inference payload:

```powershell
.\.venv\Scripts\python.exe scripts/predict_ai4i.py
```

## Batch Inference
Use a custom JSON file containing one object or an array of objects:

```powershell
.\.venv\Scripts\python.exe scripts/predict_ai4i.py --input path\to\input.json
```

The CLI prints readable JSON and does not write prediction files by default.

## Security Considerations
The model artifact uses joblib, which relies on pickle-style Python deserialization. Only load joblib artifacts generated by this project from trusted local sources. Never load untrusted model files.

## AI4I Type vs Operational Machine Type
AI4I `Type` values `L`, `M`, and `H` belong only to the external AI4I modeling feature contract. They are not equivalent to operational PostgreSQL fleet categories such as `excavator`, `wheel_loader`, or `crawler_crane`.

This phase does not map operational machine types to AI4I features. Future platform integration must define an explicit inference feature-generation contract.

## Reproducibility
The local model artifact can be regenerated from the frozen configuration and the train + validation development data. The artifact validator checks the binary SHA-256 against local metadata and verifies that the metadata matches the frozen configuration and model version.

## Limitations
AI4I is a public synthetic dataset. These predictions do not imply production readiness, causality, or performance on real industrial equipment.

## Future API Integration
Future phases may expose this inference contract through FastAPI and the web dashboard. That work is planned and is not implemented in this phase.
